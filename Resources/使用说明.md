# 小灯 · 智能体工作灯 0.9.3

原生 macOS 桌面小浮窗，显示本机 Codex、Pi、Hermes、DeepSeek Harness 的正在执行任务，并轮播本地趣味文案。

## 使用

- 双击「智能体工作灯.app」。菜单栏出现星光图标。
- 有已接入的任务时自动出现；任务全部结束后停留 8 秒收起。
- 浮窗空白区域可以拖动；点击智能体数量一行展开或收起详情。
- 点击右上角「…」或菜单栏图标可以显示浮窗、暂停显示、预览样式、设置轮播间隔。
- 「空闲时也显示」可以让小灯一直陪着你；默认关闭。
- 默认每 20 秒换一句。可以在菜单里选择 15/20/30/60 秒。
- 「主题」可选择跟随系统、深色「夜航」、浅色「晨光」、暖纸「午后」。切换立即生效并记住选择；跟随系统会响应 macOS 外观变化。
- 工作时左侧核心呼吸发光，外围光弧和光点旋转，任务数量旁显示动态信号条。等待确认时切换为琥珀色脉冲，全部结束时显示短暂扩散光环与勾号。
- 「工作动画」可以独立关闭并记住选择。系统开启「减少动态效果」时显示静态状态；浮窗隐藏、屏幕休眠或会话锁定时暂停连续动画。
- 「任务结束提示音」默认开启，使用轻柔的系统 Glass 音效；可以关闭，也可以点击「试听提示音」。系统音量和静音设置仍然生效。
- 单个已接入任务结束就可以提示，不必等其他智能体全部结束；同一轮检测中多个任务结束会合并响一次。
- 启动、重连、示例预览、重复完成事件不响。关闭提示音期间的事件不会在重新开启后补响。暂停显示只隐藏浮窗，提示音开关独立控制声音。
- 「编辑轮播文案」打开本地 JSON 句库。保存后下次轮播生效；每句最多 50 字。
- 「预览浮窗」显示明确标注的示例任务；退出预览回到真实状态。
- 退出小灯会同时退出它自己的采集子进程，不会结束智能体任务。
- 本版不会自动设置开机启动。需要时可在 macOS「系统设置 → 通用 → 登录项」添加该应用。

## 通信动画

浮窗显示「智能体 ↔ 大模型」通道；优先显示正在播放近期通信的任务，其余约每 6 秒轮换，展开详情可分别查看完整原理图。

- 请求已发起：金色粒子蓄能、发射，并在模型端扩散；一次请求最多播放 2.8 秒，随后等待新响应。
- 正在接收内容：光点向智能体移动；3 秒没有新内容事件便停止。
- 执行本地工具：智能体端播放组织、调度、工具和回填的闭环示意，突出当前观察到的工具阶段；模型计算示意保持静止，近期通信光流仍可以显示。
- 观察到响应：本地日志或响应统计已确认一次响应，短暂提示后显示「响应已记录」。
- 等待你的确认：暂停通信光点。
- 收发阶段未确认：目前仅确认任务运行，不推测模型行为。

Pi 可以观察请求与内容增量；更新本地扩展后，新会话自动加载，已有会话需自行 `/reload`。Codex 与 DeepSeek 以落盘日志为准，DeepSeek 更新受持久化检查点影响。Hermes 当前只能确认响应结束统计。光点只表示已观察的方向，不代表实际网络包或 token 数量；不会保存问题、回答或工具参数。预览模式显示演示标记。

工作阶段与近期通信分别保存：即使同一轮检测中已经开始执行工具，之前的响应到达也会保留并播放。短事件从采集器交付后展示，过期后停止；启动、重连和展开切换不重播历史。日志中的工具结果准备好时显示「结果回填示意 · 非网络发送遥测」，不声称已经发送网络请求；明确的请求事件显示「近期请求发起」。因此光流可在工具阶段出现，但不表示模型正在生成。

等待模型响应时，模型端用层叠矩阵表现常见自回归模型中的上下文关联和特征变换；接收期间显示逐 token 生成的符号。模型内部始终带「原理示意」标识，不表示已观测到真实注意力、层数或计算进度。token 方块与亮度不代表实际输出数量或 TPS。智能体闭环的光点同样是机制示意，不表示四个子阶段已经逐项真实完成。

收起时显示简化动效，展开后显示机制图与文字标签。已经结束的响应只短暂提示到达，不再播放模型计算；等待确认、未确认及等待后续事件也不播放模型计算。

动画开关、系统「减少动态效果」、隐藏与屏幕休眠继续控制通信动画。

## 协作光环

两侧采用「协作光环」工作动效。智能体侧显示卡片归拢、文字扫描、节点调度与工具结果回流；模型侧显示光栈浮动、矩阵扫描、层间传递与生成符号弹出。工具阶段突出智能体，等待模型响应时突出模型原理示意，接收内容时两侧协作。已经结束的响应不会继续播放模型生成。

未确认阶段、等待后续事件和历史响应阶段，只保留呼吸、轻微浮动等待命动效，不表示模型正在计算。等待确认和已结束卡片暂停两侧工作动效；即使其他任务仍在运行，该卡片也会保持暂停。恢复时延续自己的动画位置。

两侧动效随现有自适应节奏轻微加快，但真实请求／响应光流仍使用原有事件时序与有效期。所有卡片、矩阵、节点和生成符号均为原理示意，不是模型内部遥测、实际 token 计数或 TPS。

## 微风发电

智能体与模型之间增加了一个微型风力发电场景，收起和展开时都能看到。三叶风机缓缓旋转，草叶和云轻轻移动。它是陪伴动效，转速不代表模型速度、TPS、实际风速或任务进度。

- 有任务工作时平缓旋转；全部任务等待确认时逐渐降速，通信光流仍保持暂停。
- 点击风机可以「吹一阵轻风」，短暂加速后恢复原来的节奏，不影响任务执行。
- 切换任务或展开方式时保持转子位置；多个可见风机共用一个动画时钟。
- 关闭「工作动画」、系统开启「减少动态效果」、隐藏浮窗或屏幕休眠时保持静态，恢复时不快进停留期间的旋转。
- 全部任务结束后，风景随现有的八秒结束提示一起停留。此时任务数为零，不播放模型计算或历史收发，也不表示业务结果一定成功。

原有状态、TPS、轮播句库、声音和主题设置继续使用。

## 等高图形与流星背景

智能体、风车和模型按三列等距、等高排列，收起与展开使用相同的图形比例。常驻的两条通信连线已去掉，只在观察到相应事件时显示较大的发送／接收光核和拖尾。标题、状态说明、详情、TPS 和文案的字号也同步加大。

「…」菜单中的「流星背景」可以独立开启或关闭，默认开启；「流星亮度」提供 15%、25%、40%、60%，默认 25%。流星在整个浮窗的文字和图形后方斜掠，不拦截点击或拖动。背景仅作陪伴，不表示任务进度、真实请求或模型计算。

流星与风车共用可见动画时钟，关闭「工作动画」、隐藏、休眠、锁屏或开启系统「减少动态效果」时不播放流星移动。空闲时主动保留浮窗可继续显示陪伴背景；真实任务数及收发阶段仍按实际状态显示。

## 极光帷幕与远山

「…」菜单中的「极光帷幕」可以独立开启或关闭，默认开启；「极光强度」提供 15%、18%、30%、45%、70%，默认 18%。「远处山脊」可单独关闭地景。晨光下为柔和映彩，夜航下更接近极光夜空的观感。

极光按自然光幕的视觉特征绘制，包含弯曲光带、竖向光柱、褶皱和上下渐隐；它是装饰场景，不是气象观测或物理仿真。流星与极光各自独立运动，流星经过时不触发极光提亮，也不表达模型内部活动或真实收发。

极光约每秒重绘 12 次，与现有可见时钟共用暂停规则。关闭工作动画或系统开启「减少动态效果」时保留静态极光；隐藏浮窗、休眠和锁屏时暂停，恢复时不快进。

## 随忙碌程度加速

菜单中的「随忙碌程度加速」默认开启，「当前节奏」显示平稳、活跃、繁忙或很忙。按已确认正在运行的任务数分档：1 个为基础节奏，2 个轻微加速，3～5 个明显加速，6 个以上进入最高档。等待确认、已结束的任务不计入加速。

近十秒内首次观察到的请求、响应或结果回填活动，累计达到 2、5、10 个也可提高档位；重复快照不重复计数，启动与重连不补算历史。该规则只表达已观察的活动密度，不是 CPU 负载、TPS 或完成进度。

风车最高约为基础速度的 2.2 倍，流星最高 1.65 倍，极光最高 1.18 倍。升降速平滑进行，任务减少或活动变少后自动降速，全部等待确认时恢复等待节奏。各层通过累积时间保持连续，不会因切档突然跳位置；渲染帧率保持原样。

关闭该选项可恢复固定节奏，点击风机仍可临时吹风。真实收发光流仍按原来的事件与有效期展示，不通过加速播放推测网络吞吐或生成速度；工作动画开关及系统减少动态效果始终优先。

## 每个任务的 TPS

展开详情后，任务第二行显示独立的速度读数。

- `42.8 TPS · 实时`：仅在流式接口提供至少两次递增的实际输出 token 计数时显示，按最近约 5 秒计数与接收时间差计算。持续 3 秒没有新计数时失效。
- `28.6 TPS · 均速`：最近一次模型响应的输出 token 数除以实际请求耗时。包含首 token 等待，不包含工具执行；最多保留 5 分钟，并限制在当前任务内。提供商已计入输出的推理 token 不会被重复相加。
- `TPS 采样中`：尚无有效计数或请求计时。提供商只在末尾上报用量时，要等响应结束才有均速。
- `TPS — · 工具中`：正在执行工具，尚无上一响应的有效速度。已有均速时保留均速标签，不把工具时间加入分母。
- `TPS 待接入`：当前 Pi 会话仍加载旧扩展，需要 `/reload` 或重新启动该 Pi 会话。
- `TPS —`：没有可靠数据；悬停可查看具体原因。

Pi 需加载本版 `agent-lantern.ts` 扩展。连续使用量支持取决于提供商；仅有最终用量的 OpenAI / Anthropic 等响应不会被误标为实时。

Hermes 使用随包提供的 `hermes-metrics` 插件。把应用 `Contents/Resources/hermes-metrics` 目录复制到 `~/.hermes/plugins/agent-lantern-metrics`，运行 `hermes plugins enable agent-lantern-metrics`。下次启动 Hermes 后，每次响应结束会记录均速所需的输出 token 数和请求耗时。命名 profile 需要将插件放到相应 profile 的 plugins 目录并用 `hermes --profile 名称 plugins enable agent-lantern-metrics` 启用。插件只记录数值、会话与进程身份，不记录请求、回答、工具参数或凭据。

Codex 当前本地日志虽然包含 token 用量，但缺少单次模型请求的完整计时及实时 token 计数，因此显示 `TPS —`。本版不会用整个任务耗时、字符数或文字块数伪造 TPS。

## 四种状态来源

Codex：只读已打开的会话 JSONL，按 `task_started`、`task_complete`、`turn_aborted` 等事件计数。通过进程持有的文件检查会话仍属于活进程，避免把崩溃后的历史记录算成当前任务。长时间没有输出不会被当作完成。可识别同步 `request_user_input` 等显式输入等待；并非所有权限弹窗都能识别。

Pi：使用独立扩展 `agent-lantern.ts`。它上报本地任务开始、最终 settled、心跳和进程身份，不上报问题、回答或工具参数。扩展放到 `~/.pi/agent/extensions/` 后，新 Pi 会话自动加载；现有终端会话输入 `/reload`，嵌入其他应用的 Pi 需由该应用重新启动自己的 Pi 会话。浮窗详情会提示是否接通。禁用全局扩展的 Pi 不在覆盖范围内。

0.2.1 修复了 Pi 与采集器区域设置不同时，进程启动日期的“日 月 / 月 日”格式差异导致的漏报。采集器兼容已有会话的心跳记录；新扩展固定使用 C 区域格式，不需要为此中断正在工作的 Pi。

Hermes：以 SQLite 只读模式读取默认家目录、命名 profile 和显式 `HERMES_HOME` 下未过期的 `session_turn_leases`，检查租约进程仍存活；同时读取新鲜的网关任务计数，并对同一进程去重。打开但空闲的桌面窗口不计数。不修改 Hermes 源码或数据库。缺少该租约表的旧版会明确标为未支持。无持久化租约的任务以及远端服务器上的任务可能不被覆盖。

DeepSeek Harness：浮窗显示为 `DeepSeek`。只读进程持有的 `session.lock` 所在目录及最新支持的会话日志，以 `turn/start` / `turn/end` 判断运行，按已落盘的 `approval/asked` / `approval/decided` 显示等待确认。进程退出、空闲窗口、重启前的孤立旧任务不当作当前忙碌。任务正常完成可触发已有提示音和结束动画；取消、错误、崩溃不冒充正常完成。更新频率受 Harness 持久化检查点影响。

支持普通 JSONL 和 `.jsonl.zstd` 压缩日志，当前验证格式为 v4。压缩日志需要 `zstd` 命令；本机已安装时自动发现，否则可通过 Homebrew 安装 `zstd`。默认识别 `~/.dsh/sessions`，也支持采集器当前 `DSH_HOME` 下的会话；应用进程明确标识为 DeepSeek Harness 时可识别它持有的其他会话目录。远端任务不在覆盖范围。DeepSeek Harness TPS 暂无同口径统计，显示 `TPS —`。

提示音依据：Codex 使用明确的任务完成事件；Pi 使用非中断的最终 settled 事件；Hermes 使用本次连续观察中未过期租约被释放且原进程仍存活的结束信号。租约过期、进程死亡和读取失败不会触发提示音。仅有网关计数、没有会话租约的 Hermes 工作仍显示数量，暂不保证逐项声音提醒。声音表示一次运行已结束，不保证业务结果成功。

## 状态含义

- 绿色：已确认有任务运行。
- 黄色：已识别到等待确认，或部分状态无法确认。详情显示接入情况。
- 任务结束提示代表运行结束；不保证业务结果成功，也不自动判定代码正确。
- 数字是已确认接入的任务数，不代表能自动覆盖任何未知智能体。
- 采集故障会显示状态不可用，并自动重启自己的采集器；不会展示故障前的任务为仍在运行。

## 本地文件

文案及 Pi 状态：`~/Library/Application Support/AgentLantern/`。

浮窗位置、空闲显示、轮播间隔：应用的 macOS 偏好设置。

本工具不调用模型，不上传数据；仅读取状态所必需的本地运行文件。Codex 状态记录本身可能包含对话内容，采集器只提取生命周期、收发阶段和工作目录名称，不输出或另存对话内容。

## 安装与移除

将应用放进 `/Applications`；Pi 扩展单独安装。源代码包含应用、采集器和扩展源码，使用 `python3 build.py` 在 Apple Silicon Mac 上编译。

移除时先退出小灯，再删除应用及 `~/.pi/agent/extensions/agent-lantern.ts`。若不再需要句库，也可删除 `~/Library/Application Support/AgentLantern/`。无需删除或重置智能体自己的数据。

本包是为本机制作的 Apple Silicon 构建，采用 ad-hoc 签名，未进行 Apple 公证；不是已公证的公开发行版。
